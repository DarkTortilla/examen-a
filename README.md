# Examen A — referencias de landing pages

Este repositorio contiene cuatro referencias visuales de landing pages ficticias para ejercicios de maquetación web.

Cada propuesta se encuentra en `pages/<proyecto>/` e incluye:

- `landing.png`: referencia visual completa de la landing page.
- `design.md`: guía de paleta de colores, tipografías, recursos y criterios visuales.

## Propuestas

1. Northline Studio — agencia creativa y de branding.
2. Solana Cove — viajes y escapadas costeras.
3. Bloom & Root — florería y estudio de regalos.
4. Oakline Living — interiorismo y mobiliario.

> Las imágenes son referencias de diseño generadas para este ejercicio. Los nombres, marcas, textos, precios y negocios son ficticios.
