# Northline Studio — guía visual

## Paleta de colores

| Uso | Color | HEX |
|---|---|---|
| Fondo principal | Marfil cálido | `#F5F0E6` |
| Hero / footer | Verde bosque | `#102A21` |
| Texto principal | Carbón | `#25231F` |
| CTA | Dorado mostaza | `#C6A04A` |
| Secundario | Verde oliva | `#68745F` |
| Superficie | Arena clara | `#DDD3C4` |

## Tipografía

- **Títulos:** Cormorant Garamond, 600–700.
- **Texto y navegación:** Manrope, 400–600.
- Alternativa para cuerpo: Inter.

Google Fonts:
- https://fonts.google.com/specimen/Cormorant+Garamond

## Dirección visual

Estética editorial sobria, con hero oscuro y fotografía de interiores creativos. Usar pocos iconos, tarjetas limpias, separaciones amplias y CTAs dorados. Priorizar jerarquía tipográfica y bloques de contenido verticales.
